⚠️ WARNING: This application is intentionally vulnerable for educational purposes only. Do NOT use in production. Do NOT deploy to the internet.

📋 What's in This Demo?

A deliberately vulnerable job matching website demonstrating 5 critical OWASP Top 10 vulnerabilities:

1. SQL Injection

Bypass login by injecting SQL code. Vulnerable search function.

2. Broken Access Control

Access admin panel without login. Edit other users' jobs via IDOR.

3. Auth Failures

Weak passwords, no rate limiting, credentials exposed.

4. Security Misconfiguration

Database credentials and API keys hardcoded in HTML.

5. Vulnerable Components

Outdated jQuery 1.12.4 with known CVEs.

🚀 Getting Started

Step 1: Start the Server

Using PHP built-in server:

cd c:\xampp\htdocs\EmploySmart\owasp_top_10_demo\backend php -S 192.168.199.250:8000

Or using XAMPP Apache, just place in htdocs folder.

Step 2: Open the Application

Navigate to the home page:

http://192.168.199.250:8000/frontend/index.html

Or if using Apache:

http://192.168.199.250/EmploySmart/owasp_top_10_demo/frontend/index.html

Step 3: Explore the Vulnerabilities

From the home page, access each demo:

  • Try SQL Injection
  • Access Admin Panel
  • Test IDOR
  • Read Documentation
